# きらきら おんなのこレッスン 3D
### 〜 オシャレ・おしごと・おてつだい だいすき！ 〜

4さいの おこさま が iPad / iPhone で あそべる、**ブラウザ だけで うごく 3Dゲーム** です。
「リカちゃんDS もっと！ おんなのこレッスン」ふうの *おしゃれ* × *おしごと* × *おてつだい* を、
ぜんぶ 3D で もりもり に つめこみました。

インストール ふよう・つうしん ふよう・かきん ゼロ。`index.html` を ひらくだけ。

---

## 🎮 あそびかた

1. `kirakira-lesson-3d/index.html` を Safari / Chrome で ひらく
2. がめん の どこでも タッチ すると スタート
3. まち の おみせ を タッチ すると、ひまりちゃん が あるいて いきます

> **iPad / iPhone に ホームがめん 追加**（共有 → ホーム画面に追加）すると、
> ぜんがめん の アプリ みたい に あそべます。

### ローカルで うごかす

```bash
cd kirakira-lesson-3d
python3 -m http.server 8000
# → http://localhost:8000/ を ひらく
```

（`file://` でも うごきますが、ローカルサーバー の ほうが かくじつ です）

### キャラクター モデル

あたま は きゅうめん、かお の パーツ（め・まゆ・ほっぺ・くち）は
きゅうめん の うえ に そとむき に はりつけた **たいらな しるし**（`MeshBasicMaterial`）です。
ライティング に かかわらず いつも はっきり みえるので、
どんな シーン でも かわいい ひょうじょう が たもてます。

かみ は 「うえ と よこ を おおう cap」＋「うしろあたま の back」＋「まえがみ」の 3ぶぶん に わけて、
**かお を ぜったい に かくさない** かたち に なっています。

ひょうじょう は 12しゅるい（normal / happy / smile / surprise / wink / sad / sleepy / star / love / think / proud）、
ポーズ は 16しゅるい、ワンショット アクション は 11しゅるい（wave / jump / spin / clap / curtsy / heartHands …）。
