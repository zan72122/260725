# 🎀 リナちゃん だいすき！ おしゃれ・おしごと・おてつだい

「リカちゃんDS もっと！おんなのこレッスン」風の、4さいから遊べる **3Dきせかえ＆ミニゲーム** です。
iPad / iPhone の **縦画面・横画面どちらでも** 遊べます。文字はすべてひらがな＋アイコン、まちがえてもペナルティなしの「ぜったい楽しい」設計です。

> ※ オリジナルキャラクター「リナちゃん」によるファンメイド風ゲームであり、実在の商品・ブランドとは関係ありません。

## 🚀 あそびかた（起動方法）

ブラウザで動く完全オフラインのゲームです。ビルド不要。

```bash
cd rikachan-3d-game
python3 -m http.server 8000
# → iPad/iPhone/PC のブラウザで http://<このPCのIP>:8000 をひらく
```

GitHub Pages などの静的ホスティングにフォルダごと置いてもそのまま動きます。
（Three.js は `lib/` に同梱済み・外部通信なし）

iPadのSafariなら「ホーム画面に追加」でフルスクリーンのアプリのように遊べます。

### ごほうびループ（手渡し！）
- コインは空から降りません。**お客さん（またはママの手）がコインを手渡し→リナちゃんがぶたの貯金箱にチャリン**
- スタンプは**ハンコが「ポンッ」と押される**演出つき
- スタンプ10個で **🎁プレゼント**（あたらしいおしゃれアイテムが解放！）
- ハートでロックされたアイテムを **おかいもの** できる
- クリアのたびに紙吹雪・キラキラ・ハート・ファンファーレ・**ほめボイス**（「すごーい！」「かわいい！」）
- セーブは自動（localStorage）。アプリを閉じてもつづきから

## 👶 4さい向け設計
- 文字は最小限・すべてひらがな、アイコン＆音声ガイド付き
- ボタンは指でおしやすい特大サイズ
- **失敗・ゲームオーバーなし**（まちがえても「あれれ？」だけ）
- ピンチズームや誤スクロールを防止
- 🗣️ボタンでおしゃべりON/OFF、🔊ボタンで音ON/OFF

## 🛠 技術メモ
- Three.js r160（`lib/three.min.js` 同梱、UMDビルドなので `file://` でも動作）
- キャラクター・世界はすべてプリミティブから生成（外部モデル・画像・音声ファイル一切なし）
- BGM・効果音は WebAudio によるリアルタイム合成（4曲のループBGM＋20種の効果音）
- ほめボイスは Web Speech API（日本語音声がない端末では自動でスキップ）
- 縦画面ではカメラが自動でズームアウトして全体が見える「オートフレーミング」
