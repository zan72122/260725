# やわらか そざい あそび 🫧

4さいの おんなのこ むけ、**12しゅるいの「やわらか素材」シミュレーター**です。
さわると かたちや じょうたいが かわる ものを、ゆびで こねたり、のばしたり、
きったり、とかしたり して あそべます。

iPhone / iPad の **たて画面・よこ画面 どちらにも 対応**。
ブラウザだけで うごきます（インストール不要・オフラインOK・通信なし）。

---

## あそびかた（保護者の方へ）

1. `index.html` をブラウザで開くだけです。ビルドもサーバーも不要です。
2. iPhone / iPad では Safari で開き、共有メニューから **「ホーム画面に追加」** すると
   全画面のアプリのように使えます（PWA マニフェスト同梱）。
3. 音が出ます。最初の「はじめる」タップで音声が有効になります
   （iOS の自動再生ポリシー対応）。設定 ⚙️ から音量・BGM を調整できます。

文字はすべて **ひらがな**、ボタンはすべて **絵文字＋ひらがな** なので、
まだ字が読めなくても アイコンだけで あそべます。

## しくみ（技術メモ）

すべて **バニラ JavaScript + Canvas 2D**。ライブラリ・ビルドツール・画像・音声ファイルは
一切使っていません（音は WebAudio で その場で合成、絵は Canvas で描画）。

### 物理エンジン（4種類）

**1. `js/sim/pbd.js` — Position Based Dynamics ソルバ**

7つの素材を 1つのソルバで表現しています。

- **PBF（Position Based Fluids）**: Poly6 / Spiky カーネルによる密度拘束、
  λ の計算、artificial pressure（s_corr）、XSPH 粘性
- **距離拘束ボンド**: 粒子間を バネで つなぐ。ここに
  - *降伏と塑性*（`yield` / `plastic`）… ねんどが へこんだまま になる
  - *破断*（`breakStretch`）… おもちが ちぎれる
  - *再結合*（`reform`）… ちぎれた ねんどを くっつけ直せる
- **凝集力（表面張力）**: 対ごとのスプライン力で 水滴やスライムが 丸くなる
- **熱**: 粒子ごとの温度 + 近傍拡散。しきい値で ボンドが 融解／凝固する
  （チョコが とける・かたまる の正体）
- **指コライダー**: 指を「丸い剛体」として扱い、位置を直接 押し出す。
  速度を足すだけでは 粘土は へこまないため

密度の基準値 ρ₀ は 起動時に 六角格子から数値的に求め、λ の緩和項も
そこから相対的に決めています。これにより **画面サイズが変わっても
物理の硬さが変わりません**（端末非依存）。

**2. `js/sim/grid.js` — 落砂セルオートマトン**

すな・ゆき用。セル種別（すな/濡れすな/水/雪/固雪/氷/きらきら）ごとに
落下規則と 安息角（斜めに滑る確率）を変えています。
水がしみると すなが「濡れすな」になり、形を保つ → 砂の城が作れます。
行単位のアクティブ判定で 静止領域はスキップし、3万セルでも 60fps。

**3. `js/sim/bubbles.js` — 泡ソルバ**

やわらかい反発 + 表面張力で もこもこ積み上がる「あわ」と、
空気の流れ（値ノイズ）に乗って浮遊し、接触すると体積保存で合体する
「しゃぼんだま」の 2モード。

**4. `js/sim/fibers.js` — Verlet 繊維**

わたあめの ざらめの糸。距離拘束の反復と、棒への巻き取り（吸引）。

### 描画

粒子は **メタボール風スプライト**（色ごとにキャッシュした放射グラデーション）で
オフスクリーンに描き、そのあと

1. 自分自身を 2段階ダウンスケールして ぼかす（`ctx.filter` に頼らない ぼかし）
2. ぼかしを 右下にずらして `multiply` → うちがわの かげ
3. ぼかしを 左上にずらして `lighter` → ふちの ひかり
4. `destination-in` で 元のシルエットに切り抜き

という手順で 立体感を出しています。粒子ごとにハイライトを打つと
「つぶつぶ」に見えてしまうため、かたまり全体で処理しています。

### たのしい要素

⭐ほし集め と レベルアップ（色のアンロック）／ おかおシール（素材にくっついて一緒に動く）／
かたぬきスタンプ（へこみ＋色がつく）／ きらきら／ 絵の具／ 写真モード（フレーム付きPNG保存）／
✨まほうボタン（虹色化・きらきらシャワー・ぐるぐる）／ 端末を振ると 素材も揺れる／
無重力モード／ スローモーション／ マスコットの ひとこと／ ヒント表示／
触覚フィードバック（Vibration API）／ 進捗の自動セーブ。

音は すべて WebAudio の合成音です（ぷにっ・ぱちん・ちゃぽん・びよーん・
さらさら・もぐもぐ・ファンファーレ、やさしいペンタトニックBGM）。

## 端末への やさしさ

- 端末性能（コア数・メモリ・画面）から 粒子数と解像度を自動選択
- フレームレートが落ちたら 自動で軽量モードへ（設定には残しません）
- タブが隠れたら 停止（バッテリー節約）
- `touch-action:none` / ダブルタップ拡大の抑止 / セーフエリア対応
- 素材の大きさは **画面の面積から逆算** するので、
  iPhone SE でも iPad Pro でも 同じ見え方・同じ手ごたえ
