# 生きている宝石 ― ひかりの水族館

一見すると宝石。でも中には液体と小さな生き物たちが入っています。
表面を削って面を増やすと、内部の流体と外側の光が同時に変化する、眺めて遊ぶサンドボックスゲームです。

`index.html` をブラウザで開くだけで遊べます（依存ライブラリなし・WebGL使用）。

## あそびかた

1. **🫗 そそぐ** — 棚からびんを選ぶと宝石の上に浮かび、じょうご（ろうと）が光って目印になる。
   **指で下に引っぱるほどびんが傾き**、中身が弧を描いてじょうごへ流れ落ちる。
   注いだ分だけびんは空になり、宝石の液面が上がる（途中でやめれば「すこし」になる）
   - 🟦 あおジュース / 🌸 ももジュース / ✨ きんのつぶ / 🫧 あわ / ⭐ ひかるほし / 🪼 クラゲ
2. **🔄 まわす** — ドラッグで宝石を回すと、中の液体がゆっくり流れて混ざる
3. **⛏️ けずる** — 宝石をタップすると新しい面ができる。面はレンズや鏡として働き、内部の見え方が変わる
4. **🔦 ひかり** — ドラッグで光を動かすと、壁や床に「光の水族館」が投影される

## 技術メモ

- 単一HTMLファイル・依存なし。WebGL 1 のフラグメントシェーダーで宝石をレイトレーシング
- 宝石は半空間（平面）の共通部分として表現され、「削る」= 平面を1枚追加
- 入射面で屈折 → 内部をボリュームマーチング（液体・粒子・泡・星・クラゲ）→ 内部反射1回で多重像 → 射出面でRGB分散
- 壁・床のコースティクスは各ファセットの屈折方向から投影
- 注ぎ表現は2Dキャンバスのオーバーレイ（びん・水流・じょうご・しぶき）と、シェーダー内の「落下する光の液柱」の合成。びんの液面は傾けても常に水平を保ち、注げる量は物理的に「口が液面より下がったか」で決まる
- WebAudioによる環境音とチャイム、注いでいる間はトクトク音、FPSに応じた自動品質調整つき
