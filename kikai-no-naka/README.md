# きかいのなか

**4歳児のための、ちいさな機械の中身を見るブラウザ 3D おもちゃ。**

みぢかな機械を「すけすけ」にして、中の部品を指で **さわって・ひっぱって・とめて**、
世界の状態がなめらかに変わっていくようすを、そのまま観察できます。

勝ち負けも、点数も、失敗もありません。ただ触って、原因と結果がつながっているのを
体で覚えるための道具です。

- 対象: **4歳ごろ**（文字が読めなくても遊べる）
- 端末: **iPad / iPhone の縦画面・横画面**（PC ブラウザでも動きます）
- 通信: **一切なし**。外部ファイルもゼロ。いちど開けばオフラインで遊べます。

---

## あそびかた

| そうさ | おきること |
| --- | --- |
| 下（横画面では右）の**すけすけスライダー**を動かす | 外側のケースが手前から溶けて、中の機械が見えてくる |
| 光っている部品を**さわる／なぞる** | ハンドルが回り、レバーが動き、櫛の歯がはじける |
| 動いている部品を**指で押さえる** | 全部つながっているので、機械ぜんたいが止まる |
| 何もないところを**なぞる** | 機械がぐるっと回る（2本指でつまむと拡大縮小） |
| 画面を**2回タップ** | 見る向きが正面にもどる |

はじめて開いたときは、さわれるところに矢印が出ます。さわると消え、
しばらく放っておくとまた出てきます（設定でオフにもできます）。

## 12の機械

まわす・かぜ・とき・おと・みず・ねつ、そして
けずる・ぬう・はかる・あげる・あける・ころがる。

| | 機械 | 中身 | 「連続的に変わる」もの |
| --- | --- | --- | --- |
| 1 | **ライト**（てまわし発電ライト） | 4枚の歯車列 → 発電機 → コンデンサ → 豆電球 | 回す速さ → 発電量 → たまった電気 → 明るさ。手を離しても、たまった電気のぶんだけ じわーっと光りつづける |
| 2 | **せんぷうき** | モーター（突極・巻線・整流子）→ 羽根 / ウォームギヤ → 首ふり | ダイヤル → 回転数 → 風の強さ・音の高さ。羽根を押さえるとモーターが熱をもち、コイルが赤くなる |
| 3 | **とけい**（めざまし時計） | ぜんまい → 歯車列 → がんぎ車 ⇄ アンクル ⇄ てんぷ → 針 | 巻きの残り → てんぷの振れ → 時間の進み。**てんぷをつまむと時間が止まる** |
| 4 | **オルゴール** | ハンドル → ピンのついたドラム → 15枚の櫛の歯 → 音 | 回す速さ = 曲の速さ。ふたの開きぐあい = 音のこもりぐあい |
| 5 | **みずポンプ** | レバー → ピストン → 2つの弁 → 水柱 → 口 | パイプに満ちる水・タンクの水位・出る水の量。**下の弁を押さえると、いくらこいでも出ない** |
| 6 | **トースター** | レバー → かご + バネ → 電熱線 → バイメタル → ラッチ | 熱 → バイメタルのそり → 焼け具合。**バイメタルをつまんで冷やすと、いつまでも上がらない** |
| 7 | **えんぴつけずり** | ハンドル → 遊星キャリア → 内歯車の中をころがる 2本のらせん刃 | とがりぐあい・えんぴつの長さ・たまる削りかす。とがりきると刃がから回りする。ひきだしを引くと かすがこぼれる |
| 8 | **ミシン** | はずみ車 → 上軸 → クランク → 針棒 / 天びん、ベルト → 下軸 → かま・おくり歯 | 回す速さ → ぬい目が増える速さ。**おさえを上げると布が進まなくなる**。つまみでぬい目の間隔が変わる |
| 9 | **はかり** | 皿 → 圧縮バネ → ラック → ピニオン → 針（ひげぜんまいで戻る） | のせた重さ → バネのちぢみ → 針の角度。急にのせると針が行きすぎて**ゆらゆらしてから止まる**。バネを押さえると動かない |
| 10 | **エレベーター** | ハンドル → ウォーム → 巻き取りドラム → ロープ + つりあいおもり + ラチェット | かごの高さ。**つめを押すと戻り止めが外れて、ゆっくり下りてくる**。おもりを押さえると動かない |
| 11 | **かぎ**（なんきんじょう） | かぎのギザギザ → 5本のピン → さかいめが そろう → プラグが回る → かんぬき → つる | 差し込み具合 → ピンの高さ → そろった本数。**1本でも押さえると、いくら差してもあかない** |
| 12 | **ガチャ** | ハンドル → 円ばんのポケット → カプセルを 1こ すくって半周 → すべり台 → 受け皿 | 残りの数・出た数。玉をつつくと山がくずれる。出たカプセルをさわると**パカッと開いて中身が出る** |

どれも「押さえると止まる」が共通の合言葉です。
つながっているものは、どこを押さえても全部が止まります。

## うごかしかた

`kikai-no-naka/` はビルド不要の静的サイトです。ローカルの HTTP サーバで開いてください
（ES モジュールを使うので `file://` では動きません）。

```bash
cd kikai-no-naka
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

同じ Wi-Fi の iPad から開くときは、PC の IP を使います（例 `http://192.168.0.5:8000/`）。

**ホーム画面に追加**すると、全画面のアプリとして起動し、オフラインでも遊べます
（Safari の共有 → ホーム画面に追加）。

GitHub Pages などの静的ホスティングにそのまま置いても動きます。

### 外部アセットが 1 つもないこと

3D モデル、テクスチャ画像、HDR 環境マップ、音源ファイル、Web フォント —
**どれも使っていません。**

- 歯車は本物のインボリュート歯形を計算して生成しています
- 金属のヘアラインや木目、パンの気泡は Canvas 2D で焼いています
- 金属の映り込みは、ソフトボックスを並べた小さなシーンを PMREM で畳み込んだ環境マップです
- 音は WebAudio のオシレータとノイズだけで合成しています
  （オルゴールの音は、自由端の棒の倍音比 1 : 6.27 : 17.55 を使っています）

読み込みは three.js 本体（約 1.2 MB）とアプリのコードだけです。

ガチャのカプセルは 26 個の球どうしの当たり判定を毎フレーム解いています。
これも外部の物理エンジンは使わず、位置ベースの簡単な押しのけだけで作っています。
