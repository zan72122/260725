# ぽかぽかベビーケア 3D

4歳前後の子どもが iPad/iPhone の縦画面・横画面で遊べる、Baby Care Games for Kids 風のやさしい3Dお世話ゲームです。

## 遊び方

`index.html` をブラウザで開きます。カードをタップして、ミルク・おふろ・おむつ・おきがえ・あそび・ねんねのお世話をします。

## こだわり

- タップだけで遊べる大きなUI
- 端末の縦横どちらにも追従するレスポンシブHUD
- 3Dの赤ちゃん、帽子、哺乳瓶、おふろ、毛布、おもちゃなどが切り替わる演出
- Web Audio APIの短いごほうび音、絵文字パーティクル、3Dキラキラ
- 読めなくても絵文字で分かるカード設計
