# ぽかぽかベビーケア 3D

4歳前後の子どもが iPad/iPhone の縦画面・横画面で遊べる、Baby Care Games for Kids 風のやさしい3Dお世話ゲームです。すべての成果物はこの `baby-care-3d/` フォルダ内に収めています。

## 遊び方

`index.html` をブラウザで開きます。下のカードから「ごはん」「おふろ」「きせかえ」「あそぶ」「ねんね」「お片付け」を選び、左の「おせわプロセス」ボタンを順番にタップします。

## 実装したプロセス描写

- ごはん: スタイ、哺乳瓶のくわえる/傾ける/液面低下/気泡/ぷはー/背中トントン/げっぷ、ジュースパックのストロー刺し/凹み/ズゾゾー、りんごの三日月かじり跡/芯ポイ、バナナ3回皮むき、おにぎりの海苔・米粒、クッキーくず、おしぼり、満腹時の拒否を実装。
- おふろ: 服を脱がせる、洗濯かご連鎖、お湯はり、水位、赤/青ノブ温度、手で確認、シャンプープッシュ、泡ヘア、頭/体ごとのシャワー、原因由来の汚れ、タオル、ドライヤーを実装。
- きせかえ: 頭からかぶせる、左腕、右腕、ボタンを1個ずつ、汚れ服拒否、洗濯機→干す→取り込み、靴下・靴、天気/ねんね連動を実装。
- あそぶ: キャッチボール往復、ハイハイ追跡、積み木のぐらぐら/崩壊/大爆笑、風船ラリー、太鼓、木琴音階、いないいないばあを実装。
- ねんね: げんき→あくび→目こしこし→うとうと→こっくり→すやすやの段階、歯みがき、パジャマ、カーテン、電気、絵本、速度意味つきとんとん、くま抱っこを実装。
- 横断システム: 食べこぼし→服シミ→洗濯/おふろ、遊ぶ→散らかり→片付け、おふろ→濡れ→拭くの痕跡管理、赤ちゃんの自発行動、わくわく/ふくれっ面/照れ/びっくりなどの中間感情を実装。

## 技術

Three.js の手続き型3D赤ちゃんと3D小物を中心に、哺乳瓶の移動、液面低下、紙パックの凹み、りんごの欠け、バナナの皮、泡・水位・シャワー、服の移動、ボール・積み木・風船、まぶた低下などを実際に3D空間でアニメーションさせます。DOMは操作パネルと補助的な絵表示に限定し、Web Audio APIで哺乳瓶、木琴、太鼓、崩壊音など短い反応音を鳴らします。
