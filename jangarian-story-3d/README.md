# 🐹 じゃんがりあん ものがたり (3D)

ちいさな **ジャンガリアンハムスター** になって、おにわを おさんぽする 3D ゲームです。
**4さいの おこさま** が iPad / iPhone で あそぶことを かんがえて つくりました。
たてがめん・よこがめん どちらでも あそべます。むずかしい そうさや 「まけ」 は ありません。

## うごかしかた (おうちのかたへ)

ビルドは不要です。静的ファイルのみで動きます。

### いちばん簡単な方法 (ローカルで確認)

```bash
cd jangarian-story-3d
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

※ `file://` で index.html を直接開いても動きますが、ブラウザによっては
テクスチャ生成が制限されることがあるため、簡易サーバー経由を推奨します。

### iPad / iPhone であそぶ

1. GitHub Pages・Netlify などに この `jangarian-story-3d` フォルダを公開する
   (GitHub Pages なら リポジトリの Settings → Pages で公開できます)
2. iPad / iPhone の Safari で URL を開く
3. 共有ボタン → **「ホーム画面に追加」** すると、全画面のアプリのように遊べます
   (アイコンも ハムスターに なります)

### 対象・配慮

- 文字は すべて ひらがな + 絵文字。読めなくても アイコンと 音で わかります
- 失敗・ゲームオーバー・時間制限は ありません
- 課金・広告・外部通信は ありません (ライブラリ込みで完全オフライン動作)
- 音は 端末のマナーモード / 🎵ボタンで 消せます

## 技術メモ

| 項目 | 内容 |
| --- | --- |
| 3D | Three.js r160 (`lib/three.min.js` に同梱、CDN 不要) |
| モデル | すべてプリミティブから手続き生成 (外部アセットなし) |
| サウンド | WebAudio でリアルタイム合成 (BGM シーケンサ + 効果音) |
| 保存 | localStorage |
| 対応 | iOS Safari / Chrome / Edge。縦横どちらも対応、セーフエリア考慮 |
